# Roccul Live

Front-end demo of Roccul's internal operations app. No backend: all data is in `src/data/seed.ts`, all state is in memory. Settings > Reset demo puts everything back.

    npm install
    npm run dev

Then open http://localhost:5173

Presenter keys: 1 to 7 jump to each walkthrough stop, H hides the Walkthrough pill, Cmd+K opens search.
